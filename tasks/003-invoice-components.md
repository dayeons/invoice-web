### Playwright MCP 재검증 (2026-11-19, 개발 서버)
위 스크립트 결과를 Playwright MCP로 다시 확인했습니다. 375/768px은 같은 출처 iframe을 해당 폭으로 만들어 측정했습니다.
- 정상(`/invoice/demo`): 견적서 번호 INV-2026-001, 클라이언트명, 배지 "대기", 발행일/유효기간, 항목 3행이 더미와 일치. 열 헤더 4개(항목, 수량, 단가, 금액)가 접근성 스냅샷에 보입니다.
- 데이터 정합성: 항목 금액 합계 ₩6,400,000 = 소계 = 총액. 32개 더미도 합계 ₩11,210,000이 총액과 일치합니다.
- 항목 0개(`demo-empty`): 표 대신 "견적 항목이 없습니다" 안내가 보이고 소계/총액 ₩0.
- 항목 32개(`demo-many`): 행 32개.
- 날짜/상태 없음(`demo-blank`): 발행일/유효기간 "-", 배지 0개, 긴 항목명과 클라이언트명이 줄바꿈되어 영역을 벗어나는 요소 0개.
- 배지 매핑: 대기(밝은 회색 배경, secondary), 승인(어두운 배경, default), 거절(붉은 계열, destructive)을 계산된 스타일로 확인했습니다. 이전 기록의 "승인/거절 미확인"은 해소되었습니다.
- 반응형: 4종 x 375/768/1280px 모두 가로 스크롤 없음(scrollWidth = 폭). 375px은 카드 목록(표 숨김), 768px 이상은 표.
- 콘솔: 에러 0, 경고 0.
- 금액 표기는 `formatCurrency` 출력(`₩1,500,000`)을 기준으로 하며 ROADMAP 예시와 일치합니다.
- 상태 값 목록(대기/승인/거절)은 PRD에 확정본이 없어 현재 구현 기준이며 사용자 확인이 필요합니다.
